# VOLProject
Руководство использования по программе СОЛО.
Система Определений Линий Офсайда (СОЛО) - программное обеспечение для 
построения виртуальных линий офсайда.
Данный вариант программы, VOLProject, представляет собой тестовую версию 
программного продукта. Предназначен для демонстрации визуального построения 
виртуальных линий по снимку поля.
Результаты работы программы сохраняются в папку «images» основного проекта.
# Установка
1. Разархивируйте папку с проектом.
2. Активируйте venv и установите зависимости:
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
3. В файле main.py укажите путь корневой папки проекта (строка 30):
#Путь к папке с исходными изображениями
source_folder = 'путь/к/папке/проекта/VOLProject'
4. Добавьте в папку проекта(в папку с main.py) изображения, которые необходимо 
обработать.
5. Проект готов к запуску.

# Работа с программой
1. Запуск программы.
При запуске основного исполняемого файла main.py откроется окно «image» с 
первым изображением (Рисунок 1).
![image](https://github.com/user-attachments/assets/fc6157b5-38c1-40c0-98f1-b208c4b072fa)

Рисунок 1

2. Калибровка линий.
Для успешной калибровки необходимо в открывшемся окне «image» указать 
минимум две направляющие линии красного цвета. Направляющие линии 
строятся при помощи нажатия левой кнопки мыши - сначала указывается 
начальная точка построения линии, затем конечная (Рисунок 2).
Направляющие линии можно строить по любым визуально определяемым 
объектам на снимке - линии разметки поля, цветовые полосы газона, трибуны и 
другое*.
* Опыт проводимых тестов показал, что наилучшего результата в точности построений 
можно добиться, если разместить направляющие линии так, что предполагаемая зона 
офсайда будет находиться между ними.
![image](https://github.com/user-attachments/assets/7c6fff7a-ab32-4d32-b97e-97f17df492b9)

Рисунок 2

После построения направляющих линий, для перехода к следующему этапу 
выставления линий офсайда, необходимо нажать «Esc» или «Space».**
** Случаи, когда направляющие линии сходятся в правый верхний угол изображения, 
реализованы через отражение снимка. В связи с этим, в таких случаях для корректной 
обработки и перехода к следующему этапу необходимо использовать клавишу «Space», а не 
«Esc». Данное решение является временным, и планируется к переработке.
3. Определение офсайда.
Этап выставления линий офсайда проходит в рабочем окне «output». На экране 
отображается снимок, по которому с помощью клавиш «a» и «d», можно 
передвигать жёлтую линию (Рисунок 3).
![image](https://github.com/user-attachments/assets/a2d5cb2a-24ac-4182-93a4-555836599185)

Рисунок 3

Процесс построения линий:
1) Первой строиться линия защитника (синего цвета). Для этого необходимо с 
помощью клавиш «a» и «d» навести жёлтую линию на предполагаемое место 
построения и нажать клавишу «e» (ENG).
2) Далее отобразиться линия нападающего (красного цвета). Красная линия, 
также как и жёлтая, выставляется на предполагаемое место офсайда при помощи 
клавиш «a» и «d» (Рисунок 4).
![image](https://github.com/user-attachments/assets/37ae89d5-52a0-4ddb-9048-6546416f5a0b)

Рисунок 4

3) После завершения выставления линий, для сохранения результата, необходимо 
нажать на кнопку «s». Снимки сохраняются с исходными названиями в папке 
«images» основного проекта. Пример сохранённого изображения представлен на 
рисунке 5.
![image](https://github.com/user-attachments/assets/45528b03-f339-4127-b436-3b21808288c0)

Рисунок 5

Для перехода к следующему изображению без сохранения результатов нажмите 
клавишу «w».

4. Завершение работы программы произойдёт автоматически после обработки всех 
входных изображений.
